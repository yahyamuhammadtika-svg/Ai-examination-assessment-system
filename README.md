# AI-Based System for Marking Examination Scripts and Detecting AI-Generated Answers

## Stack
Python + FastAPI + SQLite + HTML/CSS/JavaScript + Sentence Transformers.

## Run
1. Python 3.10+
2. `pip install -r requirements.txt`
3. `uvicorn app.main:app --reload`
4. Open http://127.0.0.1:8000
